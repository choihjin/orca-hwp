# rhwp 쪽 나눔 패치(0.8.7-p1)를 엔진으로 쓴다

2026-11-20. 사용자 승인.

## 문제

사용자가 비공개 실제 문서(HWP 5.1.2.0)로 시험하다 "뒤쪽에서 표가 이상하다"고 보고했다. rhwp 0.8.7은 이 문서를 57쪽으로 그렸고, 29~50쪽은 쪽마다 작은 표 하나(또는 표+제목 글상자 하나)만 있고 나머지가 비어 있었다.

- 문서 구조: 한 문단에 "글자처럼 취급" 표와 글상자가 10~26개씩 한 줄에 하나씩 들어 있다.
- 한컴이 저장한 줄 정보(LINE_SEG의 vpos·높이)로는 이 표들이 연달아 쌓인다(예: 표 25개가 약 1.4쪽).
- rhwp 0.9.1, `devel`(0a437a7e), `devel` + PR #9209 모두 같은 57쪽. `set_respect_vpos_reset` 옵션도 무관.

## 원인 (rhwp, `devel` 기준 위치)

한 문단에 글자처럼 취급하는 표·도형이 여럿일 때 저장 줄과 컨트롤을 짝짓는 계산이 세 곳에서 어긋났다.

- `src/renderer/typeset/controls/table_entry.rs` `needs_stored_line_advance`: 표 자기 줄이 아니라, 문단 안 어느 줄이든 쪽 리셋 줄이고 높이가 같으면 새 쪽을 열었다(빈 쪽 대부분의 원인).
- `src/renderer/typeset.rs` TAC 표 줄 번호: 앞 표 개수만 세어 글상자 줄만큼 어긋나고, 다른 줄의 vpos 0을 이 표의 쪽 리셋으로 읽었다.
- `src/renderer/typeset/controls/shape_flow.rs`: 한 줄에 글상자가 둘이면 줄을 두 번 쌓았다.

패치는 같은 조건(HWP5 저장 조판, 편집 전)에서 이미 쓰이던 해석기(`control_line_seg_index`)로 컨트롤의 저장 줄을 정하는 helper를 세 곳(0.8.7 이식판은 `tac_reconcile` 포함 네 곳)에 적용한다. 편집으로 줄 분할이 바뀌었거나 합성 줄이 있으면 쓰지 않는다.

## 결과 (측정)

| | 이 문서 | 보건소 | 국립국어원 | 기부 | 76076 |
|---|---:|---:|---:|---:|---:|
| npm 0.8.7 | 57쪽 | 4 | 35 | 30 | 82 |
| 0.8.7-p1 | 33쪽 | 4 | 35 | 30 | 82 |

- 0.8.7-p1에서 문단마다 새 쪽이 시작되는 줄이 한컴 저장 vpos가 0으로 되돌아가는 줄과 같다.
- 공개 표본 4개 151쪽의 SVG가 npm 0.8.7과 같다(워커 측정, 쪽별 해시). 합격 검사 7/7, 알려진 엔진 차이 2건 그대로.
- 비공개 문서는 1~22쪽이 같고 23쪽부터 바뀐다. 23~33쪽을 그림으로 확인.
- 한컴 기준 쪽 수: 미측정(저장 vpos 되돌림으로 센 하한은 28쪽, 추정). 이 문서 3~5쪽, 21쪽에는 한컴 vpos 근거가 없는 쪽 나눔이 남아 있다(큰 표가 쪽을 넘는 경우로 추정, 미조사).

## 결정

- npm 0.8.7의 JS glue·타입·LICENSE는 그대로 두고 `rhwp_bg.wasm`만 패치판으로 바꾼다. glue가 바이트까지 같아 플러그인 코드 변경이 없다. 크기 11,805,164 B(npm 11,821,756 B).
- 엔진 표시를 `0.8.7-p1`로 바꿔 자체 빌드임을 화면·정보 화면·에이전트 JSON에 드러낸다. 서드파티 고지에 "modified by this plugin"과 패치 경로를 적는다(MIT는 수정 배포 허용).
- 고정: `build/pins.json`의 `rhwp.patched`(패치 파일·WASM 해시, 툴체인, 명령). `npm run vendor:rhwp`는 npm 배포물을 검증해 싣되 WASM은 패치판 핀과 맞는지만 확인하고, 다르면 아무것도 쓰지 않고 실패한다.
- 재현: `build/build-rhwp-patched.sh`가 v0.8.7 태그에 패치를 적용해 다시 빌드하고 해시를 핀과 비교한다. 툴체인: Rust 1.93.1, wasm32-unknown-unknown, wasm-pack 0.15.0, wasm-bindgen 0.2.127, wasm-opt(binaryen 117, `-O`).
- 상류: `devel` 기준 패치와 비공개 문서 없는 재현 테스트를 rhwp에 이슈·PR로 제안한다(사용자 승인). 상류가 받아 새 버전이 나오면 그 버전으로 옮기고 이 패치를 뺀다.

## 위험

- 공식 배포물이 아닌 자체 빌드판이다. 출처·명령·해시를 위 파일로 남긴다.
- rhwp 전체 테스트는 `devel` 패치판으로 돌렸다(패치 전후 같은 결과). 0.8.7 이식판의 rhwp 테스트는 미실행이고, 공개 표본 4개와 이 문서로만 확인했다.
- 0.8.7 이식판에는 `devel`의 0.9.x 조판 수정이 없다(기존과 같음).
